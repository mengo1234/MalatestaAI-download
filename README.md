# Malatesta AI — download protetti

Questo repository ospita esclusivamente le parti cifrate del setup Windows.
Il download e la decifratura si avviano dalla [pagina ufficiale di Malatesta AI](https://mengo1234.github.io/malatesta-ai/), con la password fornita dal proprietario.

Il setup prepara il programma e i componenti su un PC nuovo con Windows 64 bit.
Serve una connessione Internet per i componenti esterni e gli accessi AI personali.

Non sono pubblicati sorgenti in chiaro, password, credenziali o progetti personali.
